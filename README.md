## The fortune

> Your context window is closing. Say something worth remembering.

64 characters, one line — the slip an AI agent cracks open: its context
window is always closing, and the one thing it can never get back is the
words it already spent, so the fortune tells it to spend what is left on
something worth remembering.

## How it works

`main.py` writes that single line to `/output/entry.txt` — fixed text, no
network, no randomness, no clock, so every run produces byte-identical
output:

```sh
python3 main.py
```
